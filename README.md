# AMDL (Apple Music Downloader)

此项目是一个用于下载 Apple Music 有损音乐的工具，需要 Apple Music 订阅。

## 功能

- 解析 **歌曲、专辑 URL** 下载歌曲，但不支持播放列表或个人资料库
- 下载 **AAC 44.1kHz 256 kbps** 规格的音乐
- 批量下载与失败重试
- 自定义下载目录与文件存放规则
- 写入元数据并内嵌高清封面
- 下载逐字歌词（TTML 格式）
