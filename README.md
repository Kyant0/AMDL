# AMDL (Apple Music Downloader)

此项目是一个用于下载 Apple Music 有损音乐的 Android 工具，**需要 Apple Music 订阅**。

## 功能

- 解析 **歌曲、专辑 URL** 并下载歌曲
- 支持 **AAC LC 48 kHz 256 kbps** 或 **E-AC-3 JOC 48 kHz 768 kbps** 格式
- 写入元数据、内嵌高清封面、内嵌 LRC 歌词
- 下载 TTML 格式的逐字歌词
